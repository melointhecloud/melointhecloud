### About

I build **AI automation systems and SaaS platforms** that run in production: WhatsApp sales and support agents, integrated CRMs, data pipelines and internal tools. I'm **co-founder of [Automatizza](https://automatizza.vercel.app) and [S.O.L ONE](https://www.solonegroup.com.br/)**, where I lead operations and architecture and take products from PRD to deploy.

I work **spec-driven**: clear specification first, code second, AI as an accelerator rather than a crutch. Currently studying Systems Analysis and Development.

### What I deliver

| | |
|---|---|
| **WhatsApp AI agents** | Support, sales and cart recovery with OpenAI, conversation memory and human handoff |
| **CRM & integrations** | Kommo, Chatwoot, Asaas, Cakto/CartPanda: data flowing between systems with no manual rework |
| **Multi-tenant SaaS** | React/Next.js dashboards + Supabase (Auth, RLS, Edge Functions), deployed on Vercel/Railway |
| **Process automation** | n8n workflows and Python/Go services for prospecting, messaging at scale and data mining |
